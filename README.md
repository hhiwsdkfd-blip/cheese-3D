# Grandmaster 3D Chess | شطرنج النخبة الملكي ثلاثي الأبعاد 👑

لعبة شطرنج ثلاثية الأبعاد احترافية وواقعية بالكامل، مستوحاة من القصور والقلاع الأوروبية الملكية الفاخرة، مع محرك ذكاء اصطناعي لتقديم الاقتراحات وتحليل الاستراتيجيات، ونظام متكامل لحفظ واستئناف ومراجعة المباريات.

---

## ✨ المميزات الرئيسية (Key Features)

### 1. 🏰 أرضية الشطرنج الملكية (Royal Chess Floor)
- رقعة شطرنج ثلاثية الأبعاد فائقة الجودة مكونة من 64 مربعاً بنسبة 1:1 بتناوب الرخام الأسود الأوبسيديان والأبيض العاجي مع انعكاسات واقعية وخشونة دقيقة (PBR Roughness & Clearcoat).
- إطار عريض من الرخام الأسود اللامع مزين بزخارف ونقوش ذهبية دقيقة مع إحداثيات الرقعة (a-h، 1-8) محفورة بذهب عيار 24.
- دعامات وزخارف زوايا ثلاثية الأبعاد مذهبة (3D Sculpted Gold Corner Brackets).
- قاعة ملكية واسعة مستوحاة من العصور الوسطى بأعمدة حجرية ضخمة، جدران قلاعية، نوافذ قوطية ملونة، أبواب خشبية منحوتة، وأشعة شمس ذهبية سينمائية دافئة (Volumetric Godrays).

### 2. ⚔️ الجيوش الملكية المدرعة (White & Black Royal Armies)
- **الجيش الأبيض الملكي (White Royal Army)**:
  - مصنوع من الرخام الأبيض العاجي والمعدن الذهبي اللامع.
  - **الملك**: تاج إمبراطوري فاخر وصولجان الصليب الذهبي.
  - **الوزير (الملكة)**: تاج ملكي مزخرف بكرات ذهبية ورداء ملكي بقصة متدرجة.
  - **الفيلان**: حراس ملكيون بدروع كتف مذهبة وقلانس دينية مقطوعة مزينة بزهرة الزنبق (Fleur-de-lis) وصولجان حربي.
  - **الحصانان**: فرسان مدرعون بدروع حربية على الجبهة والعنق ولجام ذهبي.
  - **القلعتان**: أبراج حجرية ملكية مسننة مع نهايات ذهبية ومنافذ سهام جدارية.
  - **ثمانية بيادق**: جنود صغار مدرعون بخوذات قتالية، دروع صدرية، ودروع صليبية محمولة (Heater Shields) وسيوف معلقة.
- **الجيش الأسود الملكي (Black Royal Army)**:
  - مصنوع من الأوبسيديان والأسود اللامع المصقول مع تطعيمات الذهب الخالص وقواعد رخامية سوداء بحواف ذهبية.
  - متناسق تماماً ومميز بألوان الدروع الداكنة الفاخرة.

### 3. 🤖 مساعد الشطرنج بالذكاء الاصطناعي (AI Chess Assistant)
- **اقتراح الحركات الذكية**: اقتراح أفضل نقلة تكتيكية مع تمييز المربعات على الرقعة ثلاثية الأبعاد بوهج ذهبي.
- **شرح الاستراتيجيات الأساسية**: توضيح الأفكار الافتتاحية وخطط السيطرة على الوسط وانتشار القطع وحماية الملك.
- **تسليط الضوء على الأخطاء الشائعة والتهديدات**: كشف التهديدات المباشرة، القطع المعلقة (Hanging Pieces)، ونقاط الضعف.

### 4. 💾 نظام حفظ واستئناف ومراجعة المباريات (Save / Resume & Replay)
- حفظ المباراة الجارية واستئنافها لاحقاً في أي وقت بنقرة زر واحدة.
- أرشفة تلقائية لجميع المباريات المكتملة (كش مات، استسلام، تعادل).
- وحدة تحكم لإعادة تشغيل المباريات خطوة بخطوة مع تشغيل تلقائي وتحديد السرعة وتتبع شجرة النقلات.

### 5. 🎨 تخصيص القطع والمظهر (Piece Customization)
- 4 أنماط مختلفة للقطع: **الجيش الملكي المدرع (Royal)**، **كلاسيكي شتاونتون (Classic)**، **حديث مينيماليستي (Modern)**، و**خيالي كريستالي (Fantasy)**.
- تخصيص ألوان القطع البيضاء والسوداء من لوحة ألوان ملكية فاخرة.

### 6. 👥 أنماط اللعب
- **اللعب ضد الكمبيوتر (Vs AI)** بـ 3 مستويات صعوبة: مبتدئ، متوسط، محترف.
- **اللعب بين شخصين (Pass & Play)** على نفس الشاشة.
- **التحكم بالكاميرا**: منظور اللاعب، منظور علوي استراتيجي، منظور جانبي، وتدوير حر بزاوية 360 درجة.

## 📁 ملفات التثبيت في GitHub (GitHub Setup & Installation Files)

تم إنشاء ملفات التثبيت التلقائي والنشر المباشر على GitHub:

1. **`.github/workflows/deploy.yml`**:
   - ملف سير العمل (GitHub Actions) الذي يقوم بتثبيت المشروع تلقائياً على خوادم GitHub، فحص الكود، وبناء النسخة النهائية، ثم نشرها مباشرة على **GitHub Pages**.
2. **`.github/workflows/ci.yml`**:
   - ملف الفحص المستمر (CI) الذي يقوم باختبار التثبيت وبناء المشروع والتأكد من خلوه من الأخطاء عند كل عملية Push أو Pull Request.
3. **`setup.sh`**:
   - سكريبت تشغيل فوري لنظام Linux / macOS يقوم بفحص بيئة Node.js وتثبيت الحزم واختبار البناء تلقائياً.
4. **`setup.bat`**:
   - سكريبت تشغيل فوري لنظام Windows يقوم بتثبيت وبناء المشروع بنقرة واحدة.
5. **`push-to-github.sh`**:
   - سكريبت يربط المشروع بمستودعك على GitHub ويرفع جميع الملفات بنقرة واحدة.

## 🚀 كيفية رفع المشروع إلى مستودع GitHub (How to Push to GitHub)

### الطريقة السريعة (باستخدام السكريبت):
نفذ الأمر التالي في سطر الأوامر (Terminal):
```bash
./push-to-github.sh https://github.com/USERNAME/REPO_NAME.git
```
*(استبدل الرابط برابط مستودعك الجديد على GitHub)*

### الطريقة اليدوية (الأوامر خطوة بخطوة):
```bash
# 1. إضافة وتجهيز جميع الملفات
git add -A

# 2. إنشاء commit
git commit -m "feat: Grandmaster 3D Chess with Royal Marble Hall and Armored Armies"

# 3. التأكد من اسم الفرع الرئيسي main
git branch -M main

# 4. ربط مستودع GitHub الخاص بك (ضع رابط مستودعك هنا)
git remote add origin https://github.com/USERNAME/REPO_NAME.git

# 5. رفع الكود إلى GitHub
git push -u origin main
```

## 💻 طريقة التثبيت والتشغيل محلياً (Run Locally)

### 1. باستخدام سكريبت التثبيت السريع:
- على **Linux / macOS**:
  ```bash
  ./setup.sh
  ```
- على **Windows**:
  اضغط نقرتين على ملف `setup.bat` أو نفذ في CMD:
  ```cmd
  setup.bat
  ```

### 2. باستخدام أوامر npm العادية:
```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير المحلي
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

## 🛠️ البنية التقنية (Tech Stack)

- **Three.js & WebGL**: رندر ثلاثي الأبعاد وإضاءة سينمائية وخامات رخام وذهب PBR.
- **React 19 & TypeScript**: واجهات المستخدم والتحكم الديناميكي والحالة البرمجية.
- **Tailwind CSS**: تصميم الواجهات والشاشات واللوحات الجانبية.
- **Chess.js**: محرك قواعد الشطرنج العالمية FIDE والتحقق من النقلات.
- **Web Audio API**: مؤثرات صوتية فيزيائية فورية لنقلات القطع وأصوات الكش والأسر والانتصار.
