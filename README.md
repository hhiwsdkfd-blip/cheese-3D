# Grandmaster 3D Chess | شطرنج النخبة الملكي ثلاثي الأبعاد

لعبة شطرنج ثلاثية الأبعاد احترافية وواقعية بالكامل مصممة بتقنيات الويب الحديثة (React, TypeScript, Three.js) مع أرضية الشطرنج الملكية والجيوش الملكية المدرعة، ومساعد ذكاء اصطناعي، ونظام حفظ وإعادة تشغيل المباريات.

---

## ✨ المميزات الرئيسية (Key Features)

1. **أرضية الشطرنج الملكية (Royal Chess Floor)**:
   - رقعة شطرنج ثلاثية الأبعاد فائقة الجودة مكونة من 64 مربعاً بتناوب الرخام الأسود والأبيض العاجي مع انعكاسات واقعية.
   - إطار عريض من الرخام الأسود اللامع مزين بزخارف ذهبية دقيقة وحروف وأرقام الإحداثيات المنقوشة بذهب عيار 24.
   - دعامات وزخارف زوايا ثلاثية الأبعاد مجسمة من الذهب (3D Gold Corner Brackets).
   - قاعة حجرية ملكية واسعة بأعمدة حجرية ضخمة ونوافذ قوطية مرتفعة تتدفق منها أشعة الشمس الذهبية الدافئة (Volumetric Godrays).

2. **الجيش الملكي المدرع (White & Black Royal Armies)**:
   - **الجيش الأبيض الملكي**: خامات عاجية ومعدن ذهبي لامع، ملوك بتيجان ذهبية وصولجان ملكي، فرسان مدرعون بدروع حربية، حراس ملكيون، وأبراج حجرية مسننة وبيادق بدروع الصليب وسيوف قتالية.
   - **الجيش الأسود الملكي**: دروع أوبسيديان سوداء لامعة مع تفاصيل مذهبة وقواعد رخامية فاخرة.

3. **مساعد الشطرنج الذكي (AI Chess Assistant)**:
   - تحليل معمق للوضعيات الحالية باستخدام محرك التحليل والذكاء الاصطناعي.
   - اقتراح أفضل نقلة تكتيكية مع تمييزها على الرقعة ثلاثية الأبعاد.
   - شرح الاستراتيجيات الموصى بها والتحذير من الأخطاء التكتيكية والتهديدات المباشرة.

4. **نظام حفظ واستئناف ومراجعة المباريات (Save / Resume & Match Replay)**:
   - إمكانية حفظ اللعبة الحالية في أي لحظة واستئنافها لاحقاً.
   - أرشفة تلقائية للمباريات المنتهية بنتيجة كش مات أو التعادل.
   - وحدة تحكم متكاملة لإعادة تشغيل المباريات خطوة بخطوة مع تشغيل تلقائي واستشارة المساعد الذكي.

5. **تخصيص القطع والمظهر (Piece & Board Customizer)**:
   - الاختيار بين 4 أنماط تصميم مختلفة (الجيش الملكي، كلاسيكي شتاونتون، حديث، خيالي).
   - تخصيص ألوان القطع البيضاء والسوداء مع خيارات لونية جاهزة.

6. **أنماط اللعب المتعددة (Game Modes)**:
   - نمط اللعب ضد الذكاء الاصطناعي (Player vs AI) مع مستويات متعددة (مبتدئ، متوسط، محترف).
   - نمط اللعب لشخصين على نفس الجهاز (Pass & Play / 2 Players).
   - التحكم في زوايا الكاميرا (منظور اللاعب، منظور علوي تكتيكي، منظور جانبي، وتدوير حر بزاوية 360 درجة).

## 🚀 طريقة التشغيل محلياً (Run Locally)

### المتطلبات الأساسية (Prerequisites):
- Node.js (v18 أو أحدث)
- npm أو bun أو yarn

### خطوات التثبيت:

```bash
# 1. تثبيت الحزم والمكتبات
npm install

# 2. تشغيل السيرفر المحلي في وضع التطوير
npm run dev
```

افتح المتصفح على العنوان التالي:
```
http://localhost:3000
```

### البناء للإنتاج (Production Build):
```bash
npm run build
npm start
```

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **React 19**

- **TypeScript**
- **Tailwind CSS**
- **Chess.js** (FIDE Chess Rules & Validation Engine)
- **Lucide Icons**
- **Web Audio API** (Procedural Zero-Dependency Sound Effects)
